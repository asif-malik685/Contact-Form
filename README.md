
# Contact Form Project

This is my first front-end web development project built using HTML5 and CSS3. The project features a clean and responsive contact form with custom styling, input validation, helper text, and a modern user interface.

## Features

* Full Name fields (First Name & Last Name)
* Email input field
* Message textarea
* Styled submit button
* Responsive layout
* Custom CSS styling
* Input focus effects

## Technologies Used

* HTML5
* CSS3
